## Plugin Dependencies
- When creating a plugin, check whether each required package dependency already has a shared layer under `packages/`. If it exists, use that shared layer instead of depending on the official package directly.

## Dependency Updates
- Before starting any task, check all project dependencies for updates and keep them up to date.
- Update frequency: weekly. Only perform the update if more than 1 week has passed since the last update, to avoid repeated updates on every task.
- After completing an update, record the last update date below.
- Last updated: to be filled in after the first dependency update (format: YYYY-MM-DD).
