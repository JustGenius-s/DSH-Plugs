# @just-genius/dsh-session-archive

**Settings → 会话归档**: archived sessions grouped by workspace. Delete on the right asks for a second click. Sidebar **归档会话** stays one-click (no confirm dialog).

## Install

```sh
dsh plugin --profile web add ./plugins/dsh-session-archive
```

Restart DSH web after install (bundle patch). Then open **Settings → 会话归档**.
